# Arc Flight

A small original armored-flight action prototype built with **Godot 4.7.2**.

This project is inspired by the fantasy of a powered flying suit, but uses original names, geometry, code, and procedural visuals. No Marvel/Disney assets, logos, character models, audio, or copied game content are included.

## Controls

- **WASD** — move
- **Space / Ctrl (or C)** — ascend / descend in flight
- **Shift** — boost
- **F** — toggle flight
- **Left mouse** — repulsor-style energy pulse
- **Right mouse / Q** — homing micro missile
- **R** — reset suit
- **Esc** — release/capture mouse

## Goal

Destroy 15 interceptor drones while keeping armor and arc energy online.

## Build

The GitHub Actions workflow builds Linux and Windows packages automatically from the `arc-flight-game` branch and also supports manual `workflow_dispatch`.
